# Установка NOVA

1. Скачайте `NOVA-Setup.exe` из выпуска NOVA.
2. Запустите файл и выберите папку установки, если стандартная не подходит.
3. Нажмите «Установить», затем «Запустить NOVA».

Python, Node.js, терминал и отдельный backend не нужны. Удаление доступно в «Установленных приложениях» Windows.

Для проверки целостности сравните SHA-256 установщика с `SHA256.txt`.
