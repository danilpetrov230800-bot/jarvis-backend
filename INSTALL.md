# Installation

## Windows 10/11 x64

Run `NOVA-Setup.exe`, choose the installation directory, and select **Install**.
The installer creates Start Menu entries, an optional desktop shortcut, and an
uninstaller. Python and application libraries are included.

The portable build is `NOVA-Portable.zip`; extract it and run `NOVA.exe`.

User data is stored in `%LOCALAPPDATA%\NOVA` and is not removed during a normal
application upgrade or uninstall.
