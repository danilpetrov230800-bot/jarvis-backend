# Установка NOVA

Нужен Windows 10/11 x64.

## Способ 1 — установщик

1. Скачайте `NOVA-Setup.exe`.
2. Запустите файл.
3. При необходимости смените папку.
4. Install.
5. Ярлык NOVA на рабочем столе.

Удаление: Параметры Windows → Приложения → NOVA → Удалить, либо ярлык Uninstall NOVA в меню Пуск. Профиль `%LOCALAPPDATA%\NOVA` (память, навыки) остаётся, пока вы сами не удалите папку.

## Способ 2 — portable zip

Распакуйте в `C:\NOVA` (без русских букв и скобок в пути) и запустите `NOVA.vbs`.

Если Python внутри архива ещё не ставил библиотеки, используйте `NOVA.bat` один раз.

## Первый запуск

Мастер можно пропустить. Ключ API не обязателен.

Голос работает в окне NOVA (WebView2 / Edge). Разрешите микрофон, если Windows спросит.
