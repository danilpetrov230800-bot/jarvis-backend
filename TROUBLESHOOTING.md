# Устранение неполадок

Если NOVA не запускается, откройте «Диагностику» в приложении и экспортируйте логи. Логи находятся в `%LOCALAPPDATA%\NOVA\logs`.

- Без API-ключа доступны локальные команды и текстовый режим.
- Для Ollama запустите локальный Ollama и выберите его в настройках.
- Если микрофон недоступен, NOVA продолжает работать через текст.
- При проблемах с голосом выберите другой голос Windows в настройках.

Никогда не отправляйте API-ключи или пароли вместе с логами.
