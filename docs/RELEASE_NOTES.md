# NOVA 1.5.0

Скачайте артефакты GitHub Actions с этого коммита:

- `NOVA-Setup.exe` — установщик (ярлык, меню Пуск, удаление)
- `NOVA-windows.zip` — портативная папка
- `SHA256.txt`

Установка: запустить Setup → Install → ярлык NOVA → сказать «Нова» или написать «привет».

Python, Node, Git и терминал не нужны.

Ключ API не обязателен. Память хранится в профиле Windows и не пропадает при обновлении.
