# Безопасность NOVA

- API-ключи не хранятся в коде.
- Ключи маскируются в настройках и вырезаются из логов.
- Опасные действия требуют явного подтверждения.
- Удаление файлов, исследование открытых источников и системные изменения управляются разрешениями.
- Команды не исполняются через `shell=True`.
- Калькулятор принимает только арифметику.
- Распаковка архивов отклоняет пути с `..`.
- Режим Research работает только с публичными страницами и не обходит авторизацию, CAPTCHA и пароли.
- Backup секретов создаётся только если вы сами это включили.
