# Troubleshooting

Окно не открылось: откройте `NOVA Debug` в меню Пуск или `NOVA.bat`. Лог: `%LOCALAPPDATA%\NOVA\nova.log` (или `data\nova.log` в старой папке установки).

pip install failed: поставьте в `C:\NOVA`, не в «Новая папка (2)».

Нет голоса: разрешите микрофон для NOVA / Edge WebView2.

Нет приложений: используется меню Пуск. Проверьте ярлыки.

Удаление не стирает портативный zip, только установку Setup.exe.
