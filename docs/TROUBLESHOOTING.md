# Устранение неполадок (TROUBLESHOOTING.md)

### 1. Не слышен голос ассистента при ответе
- Проверьте в Настройках, что включен переключатель **«Включить голосовой интерфейс»**.
- Если отсутствует интернет, NOVA автоматически переключается на встроенный в Windows речевой синтезатор SAPI или Web Speech.

### 2. Ошибка подключения к внешнему AI (OpenAI / Ollama)
- При отсутствии API-ключа или недоступности Ollama, NOVA автоматически переключается на локальный движок `local-rule-engine`, сохраняя доступ ко всем инструментам ПК.
- Проверьте введенный API ключ в разделе **Настройки** -> **AI Provider**.

### 3. Ошибки доступа к файлам или опасным операциям
- В разделе **Настройки** -> **Безопасность** убедитесь, что включены требуемые разрешения (например, «Удаление файлов»).
- Опасные действия требуют подтверждения пользователя.

### 4. Где найти подробные логи?
- В интерфейсе откройте вкладку **Журнал / Логи** или просмотрите локальные файлы в `data/logs/`.
