# Руководство по тестированию (TESTING.md)

## Автоматизированные тесты (pytest)
Проект содержит тестовый набор `tests/test_master_suite.py`, проверяющий сценарии TEST 01 – TEST 26:

1. **TEST 01**: Запуск NOVA, статус API и инициализация компонентов.
2. **TEST 02**: Работа в локальном режиме без API ключей.
3. **TEST 03**: Работа без микрофона в текстовом режиме.
4. **TEST 04**: Локальные текстовые команды и калькулятор.
5. **TEST 05–06**: Детекция голосового Wake Word («Нова»).
6. **TEST 07**: Запуск приложений (Блокнот, Калькулятор, Браузер).
7. **TEST 08–09**: Локальные файловые операции (Чтение, Запись, Удаление).
8. **TEST 10–11**: Сохранение и поиск по долговременной памяти.
9. **TEST 12–13**: Создание и выполнение навыков (Skills).
10. **TEST 14–17**: Мульти-агентное планирование, выполнение шагов и ретраи.
11. **TEST 18–19**: Проверка системы безопасности, разрешений и подтверждений.
12. **TEST 20**: Офлайн-режим (Local-First).
13. **TEST 21–22**: Самодиагностика и восстановление после сбоев.
14. **TEST 23–25**: Резервное копирование и восстановление SQLite БД.
15. **TEST 27 & Stress**: Проверка маскирования секретов и стресс-тест на 25+ запросов подряд.

### Запуск тестов:
```bash
python -m pytest tests/test_master_suite.py -v
```
