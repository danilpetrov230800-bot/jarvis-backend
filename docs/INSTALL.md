# Установка NOVA

## Обычная установка

1. Скачайте `NOVA-Setup.exe`.
2. Запустите файл.
3. Если Windows покажет предупреждение, выберите **Дополнительно → Выполнить в любом случае**.
4. Нажмите Install.
5. Дождитесь ярлыка NOVA на рабочем столе и в меню Пуск.
6. Откройте NOVA. Чёрная консоль не нужна.

Данные профиля хранятся отдельно от программы:

`%LOCALAPPDATA%\NOVA`

Обновление не стирает память, навыки, агентов и настройки.

## Портативная версия

Распакуйте `NOVA-Portable.zip` в папку, например `C:\NOVA`, и запустите `NOVA.exe`.

## Удаление

Меню Пуск → NOVA → Удалить NOVA, либо Параметры Windows → Приложения.

Профиль в `%LOCALAPPDATA%\NOVA` можно оставить или удалить вручную.
