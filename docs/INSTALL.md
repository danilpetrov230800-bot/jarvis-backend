# Установка и запуск NOVA (INSTALL.md)

## Вариант 1: Установка через установщик (Рекомендуется для пользователей)
1. Перейдите в папку `release/` и запустите `NOVA-Setup.exe`.
2. Дождитесь автоматической распаковки и создания ярлыка на Рабочем столе.
3. Дважды кликните по ярлыку `NOVA`.
4. В браузере или окне приложения откроется интерфейс `http://127.0.0.1:8000`.

## Вариант 2: Запуск портативной версии (Portable)
1. Распакуйте `release/NOVA-Portable.zip` в любую папку (например, `C:\NOVA`).
2. Запустите `NOVA.bat`.

## Вариант 3: Запуск из исходного кода (Для разработчиков)
```bash
# Клонирование и переход в каталог
cd workspace

# Установка зависимостей
pip install -r requirements.txt

# Запуск сервера ядра
python server.py
```
После запуска откройте `http://127.0.0.1:8000` в браузере.
