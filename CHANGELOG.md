# Changelog

## 1.0.0

Первая production-сборка NOVA для Windows.

- Локальный ассистент без API-ключа
- Голос, wake word «Нова» / NOVA, защита от эха
- Память, навыки, агенты, задачи
- Файлы, система, приложения, компьютер
- Установщик NOVA-Setup.exe, ярлык, uninstall
- Диагностика, backup/restore, журнал без секретов
