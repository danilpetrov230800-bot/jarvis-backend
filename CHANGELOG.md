# Changelog

## 1.5.0

- Added a durable SQLite core for memory, skills, tasks, permissions and audit records.
- Moved user data to the per-user NOVA application directory.
- Moved API-key persistence outside settings and protected it with Windows DPAPI.
- Added diagnostics, profile backup API and production PyInstaller/Inno Setup packaging configuration.
- Preserved the existing Russian desktop chat, local tools, provider support and test suite.
