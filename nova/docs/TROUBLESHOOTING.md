# NOVA Troubleshooting

## NOVA не запускается

1. Перезагрузите компьютер
2. Запустите от имени администратора
3. Проверьте антивирус — добавьте NOVA в исключения
4. Settings → NOVA → Diagnostics → «Проверить NOVA»

## Голос не работает

1. Settings → Voice → Тест микрофона
2. Проверьте, что микрофон подключён и разрешён в Windows
3. NOVA продолжит работать в текстовом режиме

## AI не отвечает умно

1. Settings → AI → выберите провайдер
2. Для OpenAI — введите API key
3. Для Ollama — установите Ollama и запустите модель
4. Без API NOVA работает в локальном режиме с базовыми ответами

## Offline mode

NOVA показывает «Offline mode» когда нет интернета. Локальные функции продолжают работать:
- Файлы, система, калькулятор
- Memory, Skills, Tasks
- Локальный AI

## Ошибки

Технические детали — в Logs (sidebar → Logs → Экспорт логов).

## Переустановка

1. Uninstall NOVA
2. Удалите `%LOCALAPPDATA%\NOVA` (если нужна чистая установка)
3. Установите заново

## Backup

Settings → Storage → Создать Backup перед обновлением.
