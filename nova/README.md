# NOVA

**Neural Operational & Virtual Assistant** — персональный desktop AI-ассистent для Windows.

## Быстрый старт

1. Скачайте `NOVA-Setup.exe` из папки `release/`
2. Запустите установщик
3. Нажмите **Install**
4. Запустите NOVA из меню Пуск или с рабочего стола
5. Скажите **«Нова»** или начните печатать в чате

Никаких дополнительных установок не требуется — Python, Node.js и зависимости включены в установщик.

## Возможности

- Голосовое управление (wake word «Нова»)
- Текстовый чат с AI
- Локальные инструменты (файлы, система, калькулятор)
- Skills — обучаемые автоматизации
- Agents — агентский режим для сложных задач
- Memory — долговременная память
- Offline mode — работа без интернета

## Системные требования

- Windows 10/11 x64
- 4 GB RAM (рекомендуется 8 GB)
- 500 MB свободного места
- Микрофон (опционально, для голоса)
