# NOVA

NOVA — персональный AI-помощник для Windows 10/11.

1. Скачайте `NOVA-Setup.exe`.
2. Запустите установщик и нажмите «Установить».
3. Откройте NOVA из меню «Пуск» и начните говорить или писать.

NOVA запускается без Python, Node.js, терминала и ручного запуска серверов. API-ключ необязателен: без него доступны локальные команды и текстовый режим.

Подробности: [INSTALL.md](INSTALL.md), [TROUBLESHOOTING.md](TROUBLESHOOTING.md).
