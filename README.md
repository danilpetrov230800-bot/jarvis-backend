# ✦ NOVA — Neural Operational & Virtual Assistant

**NOVA** — полноценный персональный desktop AI-ассистент и автономный агент для Windows 10/11.

---

## 🚀 Быстрый старт для пользователя

1. **Скачайте** файл `NOVA-Setup.exe` из папки [`/release/`](release/).
2. **Запустите установщик** и нажмите кнопку установки.
3. **Запустите ярлык NOVA** на рабочем столе.
4. **Начните общение**: скажите **«Нова»** или напишите команду в поле ввода!

---

## ✨ Основные возможности

- 🎙️ **Голосовой интерфейс & Wake Word**: Активация по фразе «Нова» / «NOVA», естественный синтез русской речи Neural TTS и защита от эха.
- ⚡ **Local-First & Offline**: Работает без интернета и без API ключей (калькулятор, заметки, управление звуком, запуск программ, системная информация, поиск файлов).
- 🧠 **Многоуровневая память**: Долговременная память, контекст, предпочтения, факты и экспорт/импорт в JSON/SQLite.
- 🛠️ **Visual Skill Builder**: Создание собственных цепочек действий (открыть программы, выставить звук, заблокировать ПК) без кода.
- 🤖 **Мульти-агентный режим**: Автономные агенты (File Agent, System Agent, Research Agent, Automation Agent) с планированием, выполнением и проверкой шагов.
- 🔍 **Creator-Only Research Mode**: Легальная агрегация открытых публичных источников (OSINT) без обхода паролей и защит.
- 🛡️ **Безопасность и Диагностика**: Встроенный самотест подсистем, маскирование секретов и подтверждение опасных операций.
