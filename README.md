# NOVA

NOVA — персональный голосовой AI-ассистент для Windows 10/11 x64.

1. Скачайте `NOVA-Setup.exe`.
2. Запустите установщик и нажмите **Install**.
3. Откройте NOVA через ярлык.
4. Скажите «Нова», дождитесь режима команды и говорите.

API-ключ необязателен: локальные команды, файлы, заметки, память, Skills, задачи,
системная информация и диагностика работают без него.

Техническая документация: [INSTALL.md](INSTALL.md), [ARCHITECTURE.md](ARCHITECTURE.md),
[TESTING.md](TESTING.md), [SECURITY.md](SECURITY.md), [TROUBLESHOOTING.md](TROUBLESHOOTING.md).
