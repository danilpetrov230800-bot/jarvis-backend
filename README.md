# Nova — персональный ИИ-ассистент

Nova — персональный ИИ-ассистент в стиле J.A.R.V.I.S.: **локальный ИИ без API-ключей**,
набор инструментов (погода, поиск, курсы, время, маршруты, новости), **управление ПК**,
современный интерфейс, **режим виджета** и установка как приложение (PWA).

## Возможности

- 🧠 **Локальный ИИ (Ollama)** — работает без ключей. Порядок выбора: OpenAI (если задан
  `OPENAI_API_KEY`) → локальный Ollama → демо-режим.
- 🛠 **Инструменты без ключей** (мгновенные и точные):
  - 🌤 Погода и прогноз (Open-Meteo)
  - 🔎 Веб-поиск (DuckDuckGo)
  - 📚 Википедия
  - 💱 Курсы валют (exchangerate-api)
  - 🕐 Время в любом городе
  - 🗺 Маршрут и время в пути (OSRM)
  - 📰 Новости (Google News)
  - 🧮 Калькулятор
- 🖥 **Управление ПК**: громкость, яркость, медиа (play/pause/next), блокировка,
  статус системы (CPU/RAM/батарея). Кроссплатформенно (Linux/macOS/Windows).
- 🎙️ Голосовой ввод (Web Speech API) и озвучка ответов (TTS)
- 🪟 **Режим виджета** — сворачивание в маленькое плавающее окно (перетаскивается)
- 📲 **PWA** — установка как отдельное приложение, работает офлайн-оболочка
- 💬 Потоковые ответы и память диалога

## Запуск в один клик

Ничего настраивать не нужно — запусти файл под свою систему, остальное Nova
сделает сама (поставит зависимости, локальный ИИ, скачает модель, откроет браузер):

- **Windows** — двойной клик по `start-nova.bat`
- **macOS** — двойной клик по `Nova.command`
- **Linux** — `bash start-nova.sh`

Или из терминала на любой ОС:

```bash
python run.py
```

Первый запуск дольше (скачивается модель ~2 ГБ). Пока модель качается, Nova уже
работает в демо-режиме и сама переключится на локальный ИИ, когда всё готово.
Нужен только установленный [Python 3](https://www.python.org/downloads/).

### Ручной запуск (для разработчиков)

```bash
pip install -r requirements.txt
ollama serve &
python -m uvicorn api.index:app --host 127.0.0.1 --port 8000
```

В Cloud Agent всё поднимается автоматически через `.cursor/environment.json`.

## Переменные окружения

| Переменная         | Назначение                                    | По умолчанию   |
| ------------------ | --------------------------------------------- | -------------- |
| `OPENAI_API_KEY`   | Ключ OpenAI (необязательно).                  | —              |
| `NOVA_LOCAL_MODEL` | Модель Ollama для локального ИИ.              | `qwen2.5:3b`   |
| `NOVA_MODEL`       | Модель OpenAI (если используется ключ).       | `gpt-5`        |
| `NOVA_TOOL_REPHRASE` | `1` — перефразировать ответы инструментов моделью (медленнее). | выкл. |

## API

- `GET /` — веб-интерфейс
- `GET /api/health` — статус, провайдер и модель
- `POST /api/chat` — чат с инструментами, потоковый ответ (SSE)
- `GET /api/tools/{weather,search,wiki,currency,time,route,news}` — прямой вызов инструментов
- `GET /api/system/status` · `POST /api/system/{volume,brightness,mute,media,power}` — управление ПК

## Замечание про «без цензуры»

Nova настроена как прямой, открытый ассистент. Базовые ограничения безопасности
заложены в саму модель; локальная модель Ollama работает у вас на машине без
внешней модерации, но полностью «снять цензуру» на уровне весов модели нельзя.
