# Nova — персональный ИИ-ассистент

Nova — персональный ИИ-ассистент в стиле J.A.R.V.I.S.: современный веб-интерфейс,
потоковые ответы, память диалога и голосовой ввод/озвучка.

## Возможности

- 💬 Чат с потоковой генерацией ответов (SSE) и памятью диалога
- 🎙️ Голосовой ввод (Web Speech API) и озвучка ответов (TTS)
- 🎨 Современный тёмный интерфейс с анимациями
- ⚡ Работает даже без ключа — включается локальный демо-режим
- 🧠 Реальные ответы через OpenAI Responses API при наличии `OPENAI_API_KEY`

## Запуск

```bash
pip3 install --user -r requirements.txt
python3 -m uvicorn api.index:app --host 0.0.0.0 --port 8000
```

Откройте http://localhost:8000

## Переменные окружения

| Переменная        | Назначение                                   | По умолчанию |
| ----------------- | -------------------------------------------- | ------------ |
| `OPENAI_API_KEY`  | Ключ OpenAI. Без него — демо-режим.          | —            |
| `NOVA_MODEL`      | Модель для генерации ответов.                | `gpt-5`      |

## API

- `GET /` — веб-интерфейс Nova
- `GET /api/health` — статус и информация о модели
- `POST /api/chat` — чат, потоковый ответ (`text/event-stream`)

  ```json
  { "messages": [{ "role": "user", "content": "Привет" }] }
  ```
