# NOVA для ПК

Персональный ИИ-помощник: грамотный русский, голос, поиск, погода, пробки и управление компьютером.

## Как запустить (Windows)

1. Скачайте **NOVA-windows.zip** из [Actions](https://github.com/danilpetrov230800-bot/jarvis-backend/actions) (артефакт `NOVA-windows`). Это не исходники GitHub.
2. Распакуйте архив.
3. Нажмите дважды **`NOVA.bat`**.

Откроется **окно приложения**, не вкладка браузера. Чёрную консоль не закрывайте — это рабочий процесс.

API-ключ не нужен. Ключ Groq/OpenAI можно добавить позже в Настройках для более живого диалога.

Если окно не появилось: http://127.0.0.1:8080  
Если Windows ругается: Дополнительно → Выполнить в любом случае.  
Файл из интернета: ПКМ → Свойства → Разблокировать.

## Что умеет

- Открывает сайты и программы: «открой YouTube», «запусти калькулятор».
- Погода, пробки, курс ЦБ, новости, Википедия, перевод — без ключа.
- Поиск в открытом интернете: «погугли …», «найди …».
- Управление ПК: громкость, mute, яркость, пауза трека. Панель **ПК** в окне.
- Кнопка **Виджет** сворачивает Nova в маленькое окно поверх других программ. Клик по сфере или Escape — развернуть.
- Скриншот, заметки, таймер, блокировка ПК, голос (короткие реплики, с кэшем).

## Из исходников

```bat
NOVA.bat
```

Linux / macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run.py
```

`python run.py --browser` открывает интерфейс в браузере вместо окна приложения.

## Сборка ZIP

```bash
python installer/package.py
```

Файл: `dist/NOVA-windows.zip`.

## Разработка

```bash
pip install -r requirements-dev.txt
pytest
```
