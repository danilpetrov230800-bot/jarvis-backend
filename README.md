# NOVA

Персональный ИИ-помощник для Windows.

## Установка

1. Скачайте **NOVA-Setup.exe** из [Actions](https://github.com/danilpetrov230800-bot/jarvis-backend/actions) (артефакт `NOVA-Setup`).
2. Запустите установщик. Папка по умолчанию: `%LOCALAPPDATA%\Programs\NOVA`.
3. Нажмите ярлык **NOVA** на рабочем столе.
4. Скажите «Нова» или напишите сообщение.

API-ключ не обязателен. Чёрная консоль больше не нужна — программа открывается своим окном. Память хранится в профиле Windows (`%LOCALAPPDATA%\NOVA`) и не пропадает при обновлении.

Альтернатива без установщика: артефакт `NOVA-windows` (zip) → распаковать в `C:\NOVA` → `NOVA.vbs` или `NOVA.bat`.

## Что умеет

Чат, голос, погода, пробки, курс, новости, сайты и программы, громкость и яркость, память, навыки, файлы, диагностика, резервные копии.

Подробности: [INSTALL.md](INSTALL.md), папка `docs/`.
