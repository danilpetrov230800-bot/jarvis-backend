# Nova

Nova — локальный персональный AI-ассистент с приватной моделью Ollama,
голосовым вводом, озвучиванием ответов и управлением компьютером через
подтверждаемые команды терминала.

## Возможности

- полностью локальные диалоги без облачного API;
- выбор любой установленной модели Ollama;
- голосовой ввод и синтез речи средствами браузера;
- предложения команд из обычного диалога;
- прямой запуск через `/run <команда>`;
- оценка риска и обязательное подтверждение перед выполнением;
- локальная история диалога в браузере;
- адаптивный современный интерфейс.

## Запуск

Требуются Python 3.10+ и [Ollama](https://ollama.com/).

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

ollama pull qwen2.5:7b
ollama serve
```

В другом терминале:

```bash
python server.py
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000). По умолчанию Nova
слушает только localhost и не доступна другим устройствам в сети.

Модель и адрес Ollama можно задать переменными окружения:

```bash
NOVA_MODEL=llama3.2:3b NOVA_OLLAMA_URL=http://127.0.0.1:11434 python server.py
```

## Команды

Nova не выполняет скрытые действия. Если модель считает, что для задачи нужна
команда, интерфейс покажет её текст, уровень риска и кнопку подтверждения.
Можно подготовить произвольную команду напрямую:

```text
/run python --version
```

Команда выполняется локально с правами пользователя, запустившего Nova. Поэтому
перед подтверждением всегда проверяйте команды с повышенным и критическим риском.

## Проверка

```bash
python -m unittest discover -s tests
```
