# Release files

GitHub Actions workflow `windows-release` produces:

- `NOVA-Setup.exe` — Windows installer (Start Menu, desktop shortcut, uninstall)
- `NOVA-Portable.zip` — portable folder with `NOVA.exe`
- `SHA256.txt`
- `RELEASE_NOTES.md`

Download the artifact **NOVA-Windows** from Actions, or the GitHub Release once published.
