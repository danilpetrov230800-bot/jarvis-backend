# NOVA v1.0.0 Desktop AI Release

## Official Windows Production Distribution
- **NOVA-Setup.exe**: One-click standalone Windows Installer
- **NOVA-Portable.zip**: Portable ready-to-run package

### Key Capabilities Included:
1. **Voice Pipeline**: Wake Word ('Нова', 'NOVA'), STT, Natural Russian Neural TTS (Edge-TTS + SAPI)
2. **Local-First PC Tools**: Calculator, File Explorer, System Metrics, Processes, Clipboard, Notes, Volume/Brightness
3. **AI Model Engine**: Multi-provider support (Local Rule Engine, OpenAI, Ollama, Custom)
4. **Multi-Agent Framework**: File Agent, System Agent, Research Agent, Automation Agent with planning and verification
5. **Visual Skill Builder**: Create custom multi-step actions without coding
6. **Multi-Tier Memory**: Short-term, Long-term, Preferences, Episodic, Semantic
7. **Creator-Only Research Mode**: Legal public open-source data aggregator (OSINT)
8. **Safety & Self-Test**: 15 automated diagnostic checks, granular permission guards, secret redaction, and SQLite backups
